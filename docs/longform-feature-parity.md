## Security boundary

The browser calls only Video Lab `/api/v1/...` routes. It never receives a runtime origin, provider address, bearer token, storage object path, runtime job ID, container identifier or internal health URL. Assembly accepts only owner-scoped Video Lab generation IDs; the API resolves private runtime job IDs immediately before dispatch.

## Paid acceptance result

Run `vl-e2e-2608031348-098f40` passed against immutable candidate `sha256:2129755951882d68f4636f754422318120539666482fb0ec6509901d5f0f5145` on an H100 PCIe. It proved exact two-shot Gemma enhancement, targeted prompt regeneration, first and last frames, one replacement frame with previous-success preservation, two-user FIFO isolation and queued cancellation, one anchored LTX scene, same-origin private media, stable-gateway idempotency, container-restart recovery, the 60-minute shutdown guard and provider baseline restoration. The run lasted about 35.4 minutes and cost about USD 1.94 at the provider's quoted USD 3.29/hour.

Accepted-scene assembly, complete-project rendering, provider-replacement storage rebinding and a multi-worker warm pool remain separate production gates. Interactive in-app browser acceptance was unavailable because no controllable browser session was present; the supplemental repository Playwright suite passed at desktop and mobile sizes.
